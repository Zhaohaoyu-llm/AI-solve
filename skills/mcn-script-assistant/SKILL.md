# MCN Script Assistant Skill

## 基本信息
- **Skill 名称**: mcn-script-assistant
- **版本**: v1.0
- **适用场景**: MCN 商单脚本生成，从小红书达人调研到脚本产出、合规审核、飞书文档写入的全流程
- **依赖**: 飞书开放 API（可选，用于文档自动写入）

---

## 适用场景
当你需要：
1. 接到品牌商单 brief，需要匹配合适的小红书达人
2. 需要快速产出符合达人风格的商业短视频脚本
3. 需要对商单脚本进行合规风险审核
4. 需要将脚本自动化写入飞书文档供团队协作

---

## 输入材料

### 必需输入
1. **品牌 Brief**
   - 品牌名称
   - 产品信息（品类、卖点、口味）
   - 目标人群
   - 投放平台和要求
   - 合规限制

2. **达人信息**
   - 达人主页链接或截图
   - 达人内容风格描述
   - 近期 2-3 条代表内容

### 可选输入
3. **飞书配置**
   - 飞书 App ID
   - 飞书 App Secret
   - 目标文件夹 Token

---

## 执行步骤

### Step 1: Brief 拆解
**目标**：将品牌 brief 拆解为结构化信息
**输入**：品牌 brief 原文
**输出**：品牌核心信息 + 投放要求 + 达人匹配关键词 + 合规红线
**Prompt**：见 workflow/prompts.md Step 1

### Step 2: 达人风格分析
**目标**：分析目标达人的内容风格，提炼可复用的内容公式
**输入**：达人内容样本
**输出**：风格画像 + 可复用内容公式
**Prompt**：见 workflow/prompts.md Step 2

### Step 3: 脚本生成
**目标**：基于 brief 和达人风格生成定制化脚本
**输入**：Step1 输出 + Step2 输出
**输出**：完整脚本（标题、口播、画面、产品植入点）
**Prompt**：见 workflow/prompts.md Step 3

### Step 4: 风险质检
**目标**：对脚本进行合规审核
**输入**：Step3 输出脚本
**输出**：合规检查清单 + 修改建议
**Prompt**：见 workflow/prompts.md Step 4

### Step 5: 飞书文档写入
**目标**：将最终脚本写入飞书文档
**实现**：Python 脚本调用飞书开放 API（支持 demo/live 双模式）
**代码**：见 feishu-integration/feishu_writer.py
**操作指南**：见 feishu-integration/feishu_operation_guide.md
**运行方式**：
- Demo 模式：`python feishu_writer.py`（无需凭证，生成本地 HTML 预览）
- Live 模式：`python feishu_writer.py --live`（需配置 .env，实际写入飞书）

## 输出格式

最终交付物包含：

### 1. 达人调研报告
- 10 位候选博主列表
- 每位博主的分析维度
- 最终选定博主及理由
- 内容风格拆解

### 2. 短视频脚本
`markdown
## 脚本标题
- 预期时长
- 口播文案
- 分镜设计
- 产品植入点说明
- 合规自查结果
`

### 3. 飞书文档
- 脚本已写入的飞书文档链接
- 自动化写入说明

---

## 风险检查清单

### 广告合规
- [ ] 无减肥/瘦身/减脂功效宣称
- [ ] 无降糖/控糖功效宣称
- [ ] 无医疗暗示（治疗/预防）
- [ ] 无贬低竞品
- [ ] 无虚假夸大描述
- [ ] 标注广告/合作标识

### 品牌匹配
- [ ] 产品植入场景自然
- [ ] 符合达人人设
- [ ] 口播风格与达人一致
- [ ] 目标人群匹配

### 内容质量
- [ ] 节奏适宜（30-60 秒）
- [ ] 有吸引力的钩子
- [ ] 有清晰的互动引导
- [ ] 符合小红书平台调性

## 工具要求

1. **AI 对话工具**：用于执行 Prompt（推荐 ChatGPT/Claude/Codex）

3. **飞书开放平台**：创建应用并获取 API 凭证
