## 口播文案 + 分镜

### 分镜 1 · 开场钩子（0-5秒）

| 项目 | 内容 |
|------|------|
| **画面** | 俯拍，闹钟响起，一只手按掉闹钟，镜头快速切到厨房 |
| **口播** | 姐妹们，打工人早上真的来不及做早餐啊！ |
| **字幕** | 打工人早上有多赶？ |
| **BGM** | 轻快节奏 Vlog BGM（从闹钟声自然过渡） |

### 分镜 2 · 痛点共鸣（5-12秒）

| 项目 | 内容 |
|------|------|
| **画面** | 博主半身镜头，厨房自然光，面带无奈表情 |
| **口播** | 以前我都是随便塞两片面包就出门，到10点就饿了，一上午都没精神。 |
| **字幕** | 随便吃 -> 饿 -> 没精神 |
| **BGM** | 同上，节奏略放缓 |

| 项目 | 内容 |
|------|------|
| **画面** | 博主走到冰箱前，打开冰箱门（冰箱内整洁摆放酸奶、水果等），取出蓝莓味酸奶 |

## 拍摄建议

1. **灯光**：自然光为主，早晨拍摄效果最佳
2. **色调**：暖色调，参考博主往期滤镜风格
3. **构图**：俯拍（操作台）+ 中近景（人物）交替
4. **道具**：燕麦、蓝莓、草莓、透明玻璃碗
5. **服装**：家居休闲风，符合早起场景
6. **产品露出**：确保产品包装正面清晰可见，不要遮挡品牌名
