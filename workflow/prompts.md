# AI 工作流与核心 Prompt

## 工作流架构（5 步 Agent Pipeline）

```
Brief 拆解 → 风格模仿 → 脚本生成 → 风险质检 → 写入飞书文档
```

## Step 3: 脚本生成 Prompt

### System Prompt
你是一位 MCN 短视频编剧，擅长根据达人风格定制商业脚本。你必须严格遵循达人的内容风格，让商业植入自然无痕。

### User Prompt
请为以下合作生成一条短视频脚本：

**品牌信息**：{Step1 输出}
**达人风格**：{Step2 输出}
**达人名称**：{达人昵称}

**内容要求**：
- 时长 30-60 秒
- 自然种草，禁止硬广
- 符合达人口吻和风格

## Step 4: 风险质检 Prompt

### System Prompt
你是一位广告合规审核专家，负责检查商业短视频内容的合规风险。

### User Prompt
请检查以下脚本的合规性：

```
{Step3 输出脚本}
```

### 检查清单

| 检查项 | 标准 | 结果 | 说明 |
|--------|------|------|------|
| 减肥功效宣称 | 禁止含减肥瘦身减脂等词汇 | PASS/FAIL | |
| 降糖功效宣称 | 禁止含降糖控糖等功效性表述 | PASS/FAIL | |
| 医疗暗示 | 禁止含治疗预防等医疗词汇 | PASS/FAIL | |
| 比较广告 | 禁止贬低竞品 | PASS/FAIL | |
| 虚假夸大 | 禁止超出产品实际功效的描述 | PASS/FAIL | |
| 广告标识 | 必须标注广告/合作 | PASS/FAIL | |
| 植入自然度 | 产品出现是否生硬 | PASS/FAIL | |

### 最终判定
- **ALL PASS**：脚本合规，可以投放
- **存在 FAIL**：需要修改后重新审核

## Step 5: 写入飞书文档

### 说明
此步骤为程序自动化执行，使用飞书开放 API 将最终脚本写入飞书文档。

### 运行方式

**Demo 模式**（无需凭证，生成本地预览）：
```bash
cd feishu-integration
python feishu_writer.py
```

**Live 模式**（实际写入飞书）：
```bash
cd feishu-integration
python feishu_writer.py --live
```

### 输入
- 脚本内容（Markdown 格式，默认读取 `script/script-storyboard.md`）
- 飞书 API 凭证（App ID + App Secret，配置在 `.env` 文件中）
- 目标文件夹 Token（可选）

### 输出
- 飞书文档链接（`https://bytedance.feishu.cn/docx/{document_id}`）
- 写入状态确认（block 数量、权限设置结果）

### API 调用流程
```
1. 获取 tenant_access_token → POST /auth/v3/tenant_access_token/internal
2. 创建飞书文档 → POST /docx/v1/documents
3. 获取根 block ID → GET /docx/v1/documents/{doc_id}/blocks
4. 批量写入内容块 → POST /docx/v1/documents/{doc_id}/blocks/{root_id}/children
5. 设置文档权限 → PATCH /drive/v1/permissions/{doc_id}/public
```

详细操作指南见 `feishu-integration/feishu_operation_guide.md`。
